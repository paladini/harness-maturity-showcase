# GitHub top software cohort - October 10, 2026

This snapshot imports **2,186 pinned reports** from the immutable analysis
commit
[`48e9c7d1859b77cb11712945e5f1d83aa7098256`](https://github.com/paladini/harness-maturity-analysis/commit/48e9c7d1859b77cb11712945e5f1d83aa7098256)
with `harness-score@1.8.1`. Its run identity is `github-top-software-1000`.

The new cohort adds 1,000 public software repositories selected from recorded
GitHub repository searches ordered by observed stars. Existing repositories
were excluded by canonical GitHub ID. The search results and selection ledger
define a bounded search universe, not an exhaustive list of the most popular
software on GitHub. Stars are selection metadata only and do not affect
Harness Score or ranking.

## Preserved evidence

- [Selection ledger](selection.json): selection scope, search boundaries, and
  pinned repository identities.
- [Source manifest](source-manifest.json) and
  [source history](source-history.json): the integrated upstream run.
- [Import manifest](manifest.json): immutable source links and SHA-256
  checksums for the selection evidence and every report.
- Each `.json` repository report is copied byte-for-byte from the pinned
  analysis commit.

The snapshot contains full scanner reports and no blind human ratings. Future
imports use new immutable run directories rather than rewriting this evidence.
