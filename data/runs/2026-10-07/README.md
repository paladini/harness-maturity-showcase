## Reproduction

Use a clean checkout of each exact commit in the manifest, with Git LFS smudging disabled. Scan from a separate working directory using the published npm package:

```sh
npx --yes harness-score@1.8.1 /path/to/pinned-checkout --json
```

No install, build, test, or repository script was executed in any scanned checkout. No checkout paths were excluded. The scanner reads files only; no user or system harness scopes were included. Raw reports include the absolute checkout path from the scan machine, so byte hashes differ if a reproduction uses different local paths. Numeric results should be compared at the same commit, version, configuration, and filesystem behavior.

Reports and this run manifest are historical evidence. Future refreshes must use a new run directory rather than rewrite this snapshot.
