# Random scientific software cohort

This immutable snapshot imports the scientific software cohort from the
[Harness Maturity Analysis](https://github.com/paladini/harness-maturity-analysis)
at source commit `4fc5ae0c5eebcc638a61e0473362190e0afa6fd7`.

The analysis corpus contains 3,686 pinned reports at `harness-score@1.8.1`.
This selection adds 500 unique repositories for computational biology,
scientific computing, physics, chemistry, astronomy, earth and climate science,
and related fields. Repositories were sampled reproducibly from a bounded
GitHub topic-search union. Stars describe selection provenance and do not
affect Harness Score. This scanner-only expansion includes no blind human
ratings or external-validity claim.

The pinned README and implementation evidence, exact commits, search snapshot,
eligibility decisions, and scan receipt are preserved in the
[selection ledger](selection.json), [source manifest](source-manifest.json),
[source history](source-history.json), and individual reports. The pinned
evidence audit replaced 25 out-of-scope selections with later eligible IDs in
the same frozen random order; the final cohort ends at sample rank 552.

This run contributes 500 unique repositories and 500 records at scanner version
`1.8.1`. The public index now contains 3,728 repository/version records across
3,707 repositories, including 3,727 full reports and one badge-only entry.
