# 2026-10-09 AI software popularity corpus

This snapshot imports all **651** pinned reports from the immutable analysis
merge [`b26cd4ef0fab3864c0053ddbba4c752b8678ba99`](https://github.com/paladini/harness-maturity-analysis/commit/b26cd4ef0fab3864c0053ddbba4c752b8678ba99)
with `harness-score@1.8.1`. Its named run identity is `ai-popularity-500`.

The new cohort adds 500 AI software projects across models and inference,
agents, applications, coding tools, vision and media, and memory and retrieval.
The selection ledger records canonical GitHub IDs, pinned commits, observed
stars and date, popularity ranks where supported, archived state, and
eligibility evidence. The dated discovery snapshot preserves the bounded
GitHub query union. Stars describe selection popularity, not harness maturity.
The results are scanner-only and include no blind human ratings or
external-validity claim.

`source-manifest.json` and `source-history.json` preserve the integrated
upstream run. `selection.json`, the discovery snapshot, checkout audit, and scan
receipt preserve the round's selection and scan environment evidence. The
`manifest.json` pins source SHA-256 checksums for those files and every report;
each report is copied byte-for-byte from the analysis commit.

The import replaces prior analysis-owned listings with the current 651-report
corpus while preserving all 21 community and badge records and the 21 older
`1.5.0` scanner records. The public index contains 693 repository-version
records across 672 distinct repositories.
