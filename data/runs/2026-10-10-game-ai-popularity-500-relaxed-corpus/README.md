# Video game AI popularity cohort - October 10, 2026

This revised snapshot imports **1,186 pinned reports** from the immutable
analysis commit
[`ba3ba209cc652f1c2849f8756a833b82d623faf9`](https://github.com/paladini/harness-maturity-analysis/commit/ba3ba209cc652f1c2849f8756a833b82d623faf9)
with `harness-score@1.8.1`. Its run identity is
`game-ai-popularity-500-relaxed`.

The revised selection contains 500 repositories across games created with AI,
AI used in games, game-AI course projects, and game-specific agent
configurations, skills, and tools. A repository had to be demonstrably about
creating or playing videogames. The selection ledger records the scope and
eligibility decisions; it is not a claim of a universal popularity ranking.
Stars are selection metadata, not Harness Score points. This scanner-only
cohort includes no blind human ratings.
