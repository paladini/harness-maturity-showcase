# 2026-10-09 media editing popularity corpus

This snapshot imports all **151** pinned reports from the immutable analysis
source commit [`c3eee241e04da6eaa1ebf700b3a715779a013b55`](https://github.com/paladini/harness-maturity-analysis/commit/c3eee241e04da6eaa1ebf700b3a715779a013b55)
with `harness-score@1.8.1`. Its named run identity is
`media-editing-popularity`.

The import contains 25 media editing software projects selected by observed
stars in a bounded GitHub search union. Star counts are provenance metadata,
not score inputs or a claim of a universal popularity rank. The analysis
[preregistration](https://github.com/paladini/harness-maturity-analysis/issues/7)
records the query scope and eligibility decisions. No blind human ratings are
included.

`source-manifest.json` and `source-history.json` preserve the source run.
Every report file here is byte-identical to its raw source report, with a
SHA-256 checksum in `manifest.json`. The manifest pins each repository commit
and links each listing to the immutable source commit.

The import replaced prior analysis-owned listings with the current 151-report
corpus while preserving 20 community study records and one badge-only record.
The resulting public index contains 172 unique repositories: 171 full reports
and one badge.
